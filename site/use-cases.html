Use Cases

Who uses AudioProctor and how.

AudioProctor is for any assessed student who needs audio or text support: students with reading disabilities, English Language Learners in applicable assessments, and students with IEPs or designations requiring an accommodation.

Provincial Assessment

IEP or designation requiring accommodation

A student has a designation requiring audio or text support during provincial assessments. The teacher uploads the official audio track, records their own read-aloud, or pastes the assessment text directly. The student uses the extension during the exam on their managed Chromebook: a locked player for audio, or a fullscreen reader with built-in read-aloud for text.

Small School

Flexible accommodation without infrastructure

Schools with only a few accommodation students don't need a full assistive tech platform. One teacher, one assessment (audio or text), one code. There's no provisioning, no student accounts, and no coordination with IT for each assessment.

Free tier covers it. No infrastructure required.

Common Questions

Things divisions ask before signing.

Does this work on any Chromebook?

Yes. AudioProctor works on any Chromebook running Chrome OS. For managed devices, IT can force-install the extension through Google Admin Console so teachers don't need to do anything. Unmanaged Chromebooks can also install it manually from the Chrome Web Store.

Do students need accounts?

No. Students never sign in. They enter a short access code, given verbally by the teacher, and the extension opens directly to the assessment. There is no student-facing login, no email required, and no account creation.

Who can see my assessments?

Only the teacher who created the assessment. Audio files are stored in a private storage bucket; text assessments are stored in the database. Access is controlled by row-level security tied to the teacher's Google account.

What happens when the access code expires?

Assessments and codes expire automatically after 7 days by default (the division tier allows custom expiry windows). When an assessment expires, the access code stops working and the content is deleted. Teachers can also delete assessments manually at any time from the dashboard.

What's the difference between audio and text assessments?

Audio assessments play a locked fullscreen audio player. The student listens to the recording. Text assessments display the passage in a fullscreen reader with built-in read-aloud powered by the device's text-to-speech. Both use the same access code and exit word flow.

Is this compliant with privacy legislation?

AudioProctor does not trigger a Privacy Impact Assessment under Alberta's Access to Information Act (ATIA). No student personal information is collected or stored at any point. Students are completely anonymous to the system. The only personal data processed is teacher email addresses, which are already covered by existing Google Workspace agreements.
