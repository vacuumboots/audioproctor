How it works

Three steps. No IT ticket required.

01

Teacher uploads

Sign in with your school Google account, upload an audio file or paste assessment text, and get a short access code and exit word. Takes under a minute.

02

Student enters the code

The student types the access code into the AudioProctor extension on their Chromebook. A locked fullscreen player opens for audio, or a read-aloud text reader for text assessments.

03

Teacher unlocks to exit

When the assessment is done, the teacher reads the exit word aloud. The student types it in, the player closes, and the Chromebook returns to normal.

Why AudioProctor

Designed around a real gap in how assessments work.

No student data collected

Students are anonymous to the system. No names, no student IDs, no device identifiers. This isn't just a policy. It's structural. There's no place in the database to store student information.

Deployed by IT, not installed by teachers

The Chrome extension is force-installed via Google Admin Console. Every Chromebook in the division gets it automatically. Teachers never touch a settings page.

Built for how assessments actually work

Supports both audio and text-based accommodations in a single tool. The access code model, the lockdown player, and the exit word were all designed around the real friction of delivering accommodations in the classroom.
